# 📊 Telco Customer Churn Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing customer churn in a telecommunications company using Power BI and Python. The objective is to identify customer behavior, churn patterns, and key business insights through interactive dashboards and data analysis.

The project includes data cleaning, exploratory data analysis (EDA), customer segmentation, and business intelligence visualization to help stakeholders make data-driven decisions.

---

## 🎯 Objectives

- Analyze customer churn behavior.
- Identify factors affecting customer retention.
- Perform customer segmentation.
- Build an interactive Power BI dashboard.
- Generate actionable business insights.

## 📈 Key Business Insights

- Customers with Month-to-Month contracts have the highest churn rate.
- Electronic Check payment method shows higher churn compared to other payment methods.
- Customers with longer tenure are less likely to churn.
- Higher monthly charges are associated with increased churn.
- Fiber Optic customers show relatively higher churn than DSL customers.
